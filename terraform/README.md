Terraform
Каталог для изучения Terraform. Здесь лежат конфигурационные файлы (*.tf), а служебные и потенциально чувствительные файлы исключены через .gitignore.

Что игнорируется и почему
.terraform/ — локальный кеш провайдеров и модулей, создаётся командой terraform init. Восстанавливается повторным init, в Git не нужен.

*.tfstate, *.tfstate.* — файлы состояния Terraform. Содержат чувствительные данные (пароли, ключи, ID ресурсов) и меняются при каждом apply. Для командной работы state хранится в удалённом backend'е, а не в репозитории.

crash.log, crash.*.log — логи аварийных завершений Terraform, временные отладочные файлы.

*.tfvars, *.tfvars.json — файлы значений переменных. Обычно содержат секреты и параметры конкретного окружения, поэтому не версионируются.

override.tf, override.tf.json, *_override.tf, *_override.tf.json — локальные переопределения конфигурации. Индивидуальны для каждой машины; при необходимости конкретный файл можно вернуть через !имя_файла.

.terraform.tfstate.lock.info — временный lock-файл, существует только во время выполнения apply и подобных операций.

.terraformrc, terraform.rc — пользовательские настройки Terraform CLI (credentials, зеркала провайдеров), специфичны для машины.

*.dot, planout — опциональные правила (закомментированы): вывод terraform graph и сохранённые планы. Можно включить, если пользуетесь этими командами.

Все основные файлы *.tf, .terraform.lock.hcl и шаблоны вроде *.tfvars.example остаются под контролем версий.
